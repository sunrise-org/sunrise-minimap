# Sunrise Minimap

A minimap for [Sunrise](https://github.com/sunrise-org/sunrise), as an official native mod.

It builds against the published Sunrise SDK and is listed in [sunrise-mods](https://github.com/sunrise-org/sunrise-mods)
like any other mod.
